# Оптимизатор покупок (личный MVP)

Личный инструмент: список продуктов → живые цены → оптимальная корзина под акции с порогом → экономия.

**Город:** Барнаул, Индустриальный район.  
**Сейчас в работе:** только Магнит. Пятёрочка и Самокат — позже.  
**Интерфейс сейчас:** локальный сайт в браузере. Терминал остаётся для тех же команд. Telegram-бота нет.

Этот файл — единый источник правды для человека и для следующего чата с агентом. Старые `ИНСТРУКЦИЯ.md` удалены.

## Зачем проект

Сэкономить 30–60 минут на закупку: не открывать вкладки магазинов, а получить «куда заказать / что взять / сколько сэкономишь», с учётом порогов акций и доставки.

Критерий успеха: 3 закупки подряд делаются через этот инструмент, а не через вкладки.

### Реализовано

- Алгоритм: один магазин, порог корзины (`percent`/`amount`), бесплатная доставка, добивка до порога, сравнение SKU за мл/г.
- Магнит: выбор точки, поиск `POST magnit.ru/webgate/v2/goods/search`, каталог **доставки** (`storeType=dostavka`, `catalogType=2`), цены в копейках → рубли, кэш 3 часа в SQLite.
- Баннер первого заказа с главной (`−35% от 1000 ₽`, промокод вроде БЕРИ35) — в сумму только с `--first-order`.
- Ручные постоянные пороги: `python -m tools.set_promo`.
- Локальный сайт: `python -m web.server` → http://127.0.0.1:8787 . Список, выбор SKU, доставка, «я купил», плашки «работает / частично / вручную / позже».
- CLI: живой Магнит / `--fake` / `--shelf` (полка) / `--first-order`.
- Выбор SKU: `--choose` (номера в терминале) или `--sku "2,1"` / `--sku "молоко=2"`. `1` — самый выгодный за единицу, `-` оставляет рекомендацию. В списке до 8 вариантов.
- «Я купил»: `--bought` или вопрос после `--choose`. `--paid 1480` — фактическая сумма, иначе берётся расчёт. Пишется в `savings_log`, выбранный SKU запоминается в `aliases`. `--fake --bought` в этот счёт не входит.
- Повтор: `--again` берёт список и количество последней живой покупки. `--again "яйца"` добавляет позиции.
- В терминале команда без `--plan` проводит закупку: номер SKU, доставка, «я купил». `--plan` — только расчёт. Количество: `молоко x2`, `2 x яйца`, `сахар 2 шт`.
- Доставка на этот запуск: `--delivery 189` или `--delivery 0`. Без флага остаётся 500 ₽, пока корзина не дошла до порога из `set_promo --free-delivery`.
- Следующий живой запуск Магнита подставляет запомненный SKU, если он ещё в наличии.
- Юнит-тесты: `pytest` (оптимизатор, выбор SKU, покупки, разбор товаров, баннер, ручные акции).

### Не сделано / ограничения

- Тариф доставки сайт без логина не отдаёт. На один запуск его вводят руками: `--delivery`. Порог бесплатной доставки — `python -m tools.set_promo --free-delivery`.
- Постоянные корзинные акции не парсятся автоматически — только вручную через `set_promo`.
- Нет Telegram-бота. На сайте выбор SKU уже кнопками.
- Пятёрочка / Самокат — заглушки парсеров.
- Не делать: публичный сайт, автозаказ, все сети сразу, агрессивный парсинг.

## Архитектура

```
Список текстом
    → matching.parse_list
    → MagnitParser.search (+ кэш SQLite)
    → ручные/баннерные Promo
    → optimizer.optimize_cart
    → выбор SKU (--sku / --choose) и запомненный alias
    → cli печатает план
    → --bought пишет savings_log + aliases
```

```
grocery-optimizer/
  README.md              ← ты здесь
  AGENTS.md              ← правила для AI (имя пользователя и т.п.)
  config.py              ← город, shopCode, доставка 500 ₽
  cli.py                 ← тот же расчёт в терминале
  web/server.py          ← локальный сайт, порт 8787
  requirements.txt
  db/
    schema.sql           ← stores, products, offers, promos, savings_log
    app.db               ← локальная БД (не коммитить секреты)
    __init__.py          ← init_db
    offers_cache.py      ← кэш офферов (раздельно полка / доставка)
    manual_promos.py     ← ручные акции в таблице promos
    aliases.py           ← запомненный SKU после «я купил»
    purchases.py         ← запись и чтение savings_log
  parsers/
    base.py              ← интерфейс search / fetch_promos
    magnit.py            ← живой поиск товаров
    magnit_stores.py     ← shop_by_point / stores-facade
    magnit_promos.py     ← баннер первого заказа с главной
    pyaterochka.py       ← заглушка
    samokat.py           ← заглушка
  domain/
    models.py            ← Offer, Promo, CartPlan
    optimizer.py         ← корзина, пороги, добивка, compare_sku
    matching.py          ← нормализация «молоко, хлеб»
    savings.py           ← расчёт/агрегация экономии
    selection.py         ← номера --sku и подстановка запомненного SKU
  tools/
    find_stores.py       ← выбрать Магнит → config + DB
    set_promo.py         ← записать порог / free delivery вручную
  data/fake_catalog.py   ← фейки для --fake и тестов логики
  bot/screens.py         ← тексты 6 экранов (бот ещё не подключён)
  tests/                 ← pytest
```

### Потоки данных

1. **Цены:** `cli` → `MagnitParser` → API → `Offer` → кэш `offers` (поле `catalog_mode`, напр. `dostavka:2`).
2. **Акции:** баннер главной (опционально) + строки из `promos` с `rules_json.source=manual`.
3. **План:** для каждой нужды берётся лучший SKU **за единицу** (мл/г/шт), сумма → скидка порога → доставка → `total`.
4. **База экономии:** `old_price` выбранных SKU (или цена), + доставка без оптимизатора.

## Команды

```powershell
# окружение
cd grocery-optimizer
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -c "from db import init_db; print(init_db())"

# точка Магнита
python -m tools.find_stores
python -m tools.find_stores --list-only
python -m tools.find_stores --pick 1

# акции вручную
python -m tools.set_promo --percent 1500 20
python -m tools.set_promo --free-delivery 1500
python -m tools.set_promo --list
python -m tools.set_promo --clear

# сайт
python -m web.server

# расчёт в терминале
python cli.py "молоко x2, хлеб"         # в терминале: выбор, доставка, запись
python cli.py --plan "молоко, хлеб"     # только расчёт
python cli.py --first-order "..."
python cli.py --shelf "молоко"          # полка, не доставка
python cli.py --fake --plan "молоко, хлеб"
python cli.py --choose "молоко, хлеб"   # спросить номер SKU, потом «я купил»
python cli.py --sku "2,-" --bought "молоко, хлеб"
python cli.py --sku "молоко=2" --paid 1400 "молоко, хлеб"
python cli.py --again
python cli.py --again "яйца"
python cli.py --delivery 0 "молоко, хлеб"
python cli.py --again --delivery 189
python cli.py --stats

# тесты
pytest -q
```

Если API Магнита не отвечает (DNS/SSL) — выключи VPN / Safe DNS.
